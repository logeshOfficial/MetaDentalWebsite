# External image sources

The treatment cards primarily use photographs supplied by META DENTAL. The following cards use public-domain images from Wikimedia Commons because the clinic library did not contain a distinct, relevant photograph:

- **Dentures:** [Denture Example 1](https://commons.wikimedia.org/wiki/File:Denture_Example_1.jpg), released into the public domain by DRosenbach.
- **Kids’ dentistry:** [Basic dental screening 150218-N-QK202-017](https://commons.wikimedia.org/wiki/File:Basic_dental_screening_150218-N-QK202-017.jpg), a public-domain U.S. Navy photograph.
- **Dental cleaning:** [USS New Orleans Dental Cleaning (26893225940)](https://commons.wikimedia.org/wiki/File:USS_New_Orleans_Dental_Cleaning_(26893225940).jpg), a public-domain U.S. Navy photograph.

The downloaded files were resized and converted to WebP for the treatment-card layout.
